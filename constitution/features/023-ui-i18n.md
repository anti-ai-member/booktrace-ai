# Feature 023: UI Chinese / English

## Goal

UI locale (`zh` | `en`) follows **system/browser language** by default; optional manual override via toggles on home and reader (shared state). Book content is never translated by this feature.

## In scope

1. Message catalogs + `t()` + React context.
2. Auto: `navigator.language(s)` → `zh*` = Chinese, else English; react to `languagechange` when not overridden.
3. Home topbar + reader chrome toggles (override; re-click active = follow system again).
4. Replace primary shelf and reader chrome strings (buttons, titles, aria-labels, empty states).
5. Persist override in `localStorage` (`shumai.uiLocaleOverride`).

## Out of scope

- Book text translation.
- Mobile season work.
- Third-party i18n frameworks (optional later).

## Acceptance

- Switching locale updates visible UI chrome on both surfaces without reload (and survives reload).
- Opening a book still shows original chapter text regardless of locale.
