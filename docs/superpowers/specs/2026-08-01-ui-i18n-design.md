# Design: UI i18n (zh / en)

**Status:** Implementing — system language first; optional manual override.  
**Date:** 2026-08-01

## Goal

Switch **UI chrome** between Chinese and English. Do **not** translate book body, titles from EPUB, notes content, or model answer prose.

## Locale resolution

1. **Default / auto:** `navigator.languages` / `navigator.language` — any `zh*` → `zh`, else `en`.
2. Listen to `languagechange` and re-apply when there is **no** manual override.
3. **Manual override (optional):** 中 / EN on home and reader; stored in `localStorage` (`shumai.uiLocaleOverride`). Clicking the already-active locale again clears override and returns to system.

## Placement

- Home topbar actions: `LocaleToggle`.
- Reader topbar status cluster: same `LocaleToggle`, shared state.

## Architecture

- Lightweight custom i18n (no i18next for v1).
- `messages.zh.js` / `messages.en.js` + `t(key, vars?)`.
- `LocaleProvider` in `main.jsx`.

## Out of scope

- Translating EPUB / PDF / MOBI text.
- Forcing model outputs to a language (may follow UI later).
- Full coverage of every toast on day one — prioritize shelf + reader chrome, then recovery/解惑 chrome.

## Acceptance

- Toggle on home and reader flips labels immediately and persists across reload.
- Book paragraph text unchanged when locale flips.
